Welcome to AICLEX Portal

Thank you for purchasing the AICLEX Enterprise Document Collection & Verification Portal. You have made an excellent choice!

We have designed this portal using cutting-edge technologies to ensure top-notch performance, security, and scalability. Furthermore, we built an incredible Visual Setup Wizard that installs your database and configures your app without you needing to write a single line of code.

Tech Stack Overview:
  • Framework: Next.js 14 (App Router)
  • Database: PostgreSQL (via Prisma ORM)
  • Styling: Tailwind CSS & Shadcn UI
  • Storage: Cloudflare R2 (AWS S3 Compatible)

System Prerequisites

Before you begin the installation, please ensure your system meets the following requirements:

  • Node.js: Version 18.x or 20.x installed.
  • NPM: Node Package Manager (comes with Node.js).
  • Database: A PostgreSQL Database (Free on Neon.tech or Supabase).
  • Code Editor: Visual Studio Code (Recommended).
Note: You do NOT need XAMPP, Apache, or PHP for this software. This is a modern Node.js application.

Getting Your Credentials

To use the Automated Wizard, you need to collect a few keys first.

1. Envato Purchase Code

  1. Log in to your CodeCanyon account.
  2. Go to your Downloads page.
  3. Click Download next to AICLEX and select License certificate & purchase code.
  4. Copy your Purchase Code.

2. PostgreSQL Database URL

  1. Create a free account on Neon.tech.
  2. Create a new project.
  3. Copy the Connection String. It should look like:
    postgresql://user:password@host/db?sslmode=require

3. Cloudflare R2 Storage Keys

  1. Log in to Cloudflare and go to R2 Object Storage.
  2. Create a new bucket.
  3. Click Manage R2 API Tokens and generate a token with Read/Write access.
  4. Copy the Access Key, Secret Key, and Endpoint URL.

Local Installation

Once you have extracted the ZIP file you downloaded from CodeCanyon, follow these steps:

Step 1: Install Dependencies

Open your terminal (inside the extracted folder) and run:

npm install

Step 2: Start the Server

After installation completes, start the Next.js server:

npm run dev

Step 3: Open in Browser

Open Google Chrome or Safari and navigate to:

http://localhost:3000

You will automatically be redirected to the AICLEX Setup Wizard!

The AICLEX Setup Wizard

When you open the app in your browser for the first time, you will see a beautiful 4-step installation screen.

Step 1: License Verification

Enter the Envato Purchase Code you copied earlier. Our system will securely verify your license and unlock the installer.

Step 2: Database Connection

Paste your PostgreSQL Database URL. Click Connect. The system will automatically create all the necessary tables in your database. No manual setup required!

Step 3: Storage Configuration

Enter your Cloudflare R2 Keys. The system will ping your storage bucket to ensure the keys are correct.

Step 4: Admin Account

Create your Admin Email and Password. Once you click Finish, the system will save everything securely and redirect you to the Login screen.

Deploying to Vercel (Production)

Hosting this application is incredibly simple using Vercel.

  1. Upload your configured project folder to a Private GitHub Repository.
  2. Go to Vercel.com and click Add New Project.
  3. Import your GitHub repository.
  4. Before clicking Deploy, open the Environment Variables tab.
  5. Copy all the keys from your local .env file (which the wizard created for you) and paste them into Vercel.
  6. Click Deploy!
